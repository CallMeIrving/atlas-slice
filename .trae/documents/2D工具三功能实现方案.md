## 任务一：智能图集打包（atlaspack）
### 核心 `src/core/pack.ts`
- 类型：`PackItem{ id,name,width,height }`、`PackOptions{ padding,margin,maxSize,allowRotate,powerOfTwo,trim,alphaThreshold }`、`PackPlacement{ id,name,x,y,w,h,rotated,trimmed,sourceSize,contentOffset }`、`PackResult{ width,height,placements,fillRatio }`。
- `packRects(items, opts): PackResult`：MaxRects + BSSF（short-side-fit）打分，支持 90° 旋转（同时试探 `(w,h)` 与 `(h,w)`）。
- **智能尺寸**：面积下界 `ceil(sqrt(totalArea*1.05))` → 生成候选边长（step 16px；`powerOfTwo` 时取 2 的幂），按面积升序逐个装箱，命中即停，封顶 `maxSize`（默认 4096）与候选数上限（≤24），避免反复全量装箱造成卡顿。全部失败抛「素材超出最大尺寸」。
- **trim**：对每张图 `trimBBox(imageToImageData(img), threshold)` 求内容盒，记录 `contentOffset`；全透明图跳过。裁剪关闭时内容盒 = 整图。
- `renderAtlas(items, result, opts): { canvas, meta: Record<string,FrameMeta> }`：按 `placements` 绘制（旋转帧对 canvas 做 90° 变换），生成 `meta`（复用共享 `FrameMeta`）。
- 命名：`applyNaming('{name}', name, i)` 保证唯一。

### 页面 `src/components/AtlasPackPage.vue`
- 侧栏：`<input multiple>` 多选导入（图片列表可删除）；参数 padding / margin / 最大尺寸 / 允许旋转 / 2 的幂 / 裁剪透明边 / 元数据格式（JSON、可选 plist）/ 图集文件名；「开始打包」+「导出 ZIP」+「重置」。
- 主区：打包结果用 `<img>` 展示，叠加绝对定位 overlay（按 `placement` 与图集尺寸换算百分比）画每个素材框，hover 高亮并显示名称/尺寸；顶部统计「N 张 → W×H，填充率 X%」。
- 导出：`downloadZip([{atlas.png}, {atlas.json}, 可选 plist], '<name>-atlas.zip')`。

## 任务二：多方向精灵（directionsprite）
> 用户确认能力：**单方向 → 合成多方向**。核心是「镜像/旋转派生方向 + 排成方向图集」。镜像只能派生左右；上下/斜向若无法由镜像得出，UI 必须明确标「未生成·需指定来源」，绝不伪造美术。

### 核心 `src/core/direction-sprite.ts`
- `DIRECTION_SETS: Record<2|4|8, DirectionKey[]>`（2 向：右/左；4 向：下/左/右/上；8 向含四对角）。
- `DirectionSlot{ key,label,source:'base'|null,transform,enabled }`，`transform ∈ none|mirrorX|mirrorY|rot180|rot90|rot270`（`mirrorX` 用于角色左右补全；旋转类便于投射物/箭头派生多方向）。
- `transformFrame(image, transform): HTMLCanvasElement`：按变换绘制到新画布（旋转后尺寸交换）。
- `buildDirectionAtlas(slots, frames): { columns, rows, cellW, cellH, cells: { dir,index,x,y,w,h }[] }`：行=启用的方向、列=帧序；cell 尺寸取所有已生成帧的最大值，逐格居中。
- `directionFrameName(base, dir, index)` → `{base}_{dir}_{00}.png`。

### 页面 `src/components/DirectionSpritePage.vue`
- 侧栏：多选导入「基准方向」帧序列（**按文件名自然排序**，列表可删）；方向集选择（2/4/8）；方向槽表：每行「启用 + 源（基准）+ 变换」，默认 右=`none`、左=`mirrorX`，其余默认关闭并提示「镜像无法派生该方向，请单独提供素材或改用旋转」；单元格尺寸/留白参数；导出。
- 主区：方向 × 帧 的表格预览（未生成方向整行灰显并标注）；顶部统计「M 个方向 · K 帧」。
- 导出：方向图集 PNG + `buildAtlasJson` 的 JSON（cell 名含方向与帧索引），命名模板复用 `applyNaming` 风格。

## 任务三：Tilemap 切片（tilemap）
### 核心 `src/core/tilemap.ts`
- 类型：`TilesetOptions{ tileW,tileH,margin,spacing,offsetX,offsetY,skipEmpty,alphaThreshold }`、`TileRect{ col,row,index,x,y,w,h }`。
- `enumerateTiles(imgW,imgH,opts): TileRect[]`（纯几何，网格预览与导出共用）：列数 = `floor((W - 2*margin + spacing) / (tileW + spacing))`，行数同理；`offsetX/offsetY` 额外跳过左上区域。
- `isEmptyTile(imageData, rect, threshold)`：用 `trimBBox` 判定全透明块。
- `buildTiledJson(...)`：输出 Tiled 兼容字段 `type:'tileset', name, image, imagewidth, imageheight, tilewidth, tileheight, tilecount, columns, margin, spacing`。
- `sliceTile(image, rect): string`（dataURL PNG）。

### 页面 `src/components/TilemapPage.vue`
- 侧栏：单图导入；tile 宽高、margin、spacing、偏移、跳过空白 tile、tile 命名模板（默认 `{name}_{index}.png`，`{col}/{row}` 可用）；导出 ZIP + 重置。
- 主区：画布叠加网格预览，hover 高亮当前 tile 并显示 `col,row,index`；顶部统计「columns × rows = N 块（跳过空白后 M 块）」。
- 导出：`downloadZip([单块 PNG..., tileset.json], '<name>-tileset.zip')`。

## 风险与坑
- **旋转帧元数据**：`frame` 必须记旋转后的实际打包 w/h 且 `rotated:true`，`sourceSize` 记未旋转原尺寸；绘制时对 canvas 施加 90° 变换，否则回读错位（见共享层约定）。
- **装箱复杂度**：候选尺寸集合封顶 + 迭代上限，避免 O(n²) 反复全量装箱。
- **无法派生方向**：UI 明确「未生成/需指定来源」，不伪造上/下美术。
- **大图集内存**：`maxSize` 上限、绘制后 `releaseCanvas`、只 `toBlob` 一次；超阈值给 warn。
- **热更新/切页丢缓存**：沿用 `watch(hasSource, { immediate: true })` 模式，从 store 里的 blob URL 重新解码并重算（多文件页重建文件列表），防止预览空白。
- **blob 泄漏**：多选导入与 reset 必须成对 revoke。

# 去水印模块实现方案

## Context

当前工具已覆盖「精灵图切片 / 单图抠图 / 视频抽帧 + 裁切 + 抠图」，但素材里的水印无法处理：水印会以像素形式残留在导出结果中，半透明水印还会干扰后续抠图（白色水印饱和度接近 0，色相判据会把它判成前景，在透明结果里留下一块水印形状的岛）。

本次新增一个**独立的「去水印」页面**，用零模型本地算法把水印从画面中还原掉，并与既有帧数据链路打通（帧列表、裁切、抠图、导出）。

已与用户确认的范围：

1. 形态：顶栏新增第 4 个页签，**同时支持视频帧与单张图片**。
2. 算法：**零模型本地算法**，不引入 AI inpaint 与新的模型权重下载通道。
3. **不接入**一键处理流水线（`frame-pipeline.ts` / `FramePipelineModal.vue` 不动）。
4. 区域：**手动框选 + 自动框选 + 调整大小与位置**都要支持。

---

## 一、核心场景：纯色背景 + 角落水印怎么处理

这是本模块的重点，结论是**不该上 inpainting 模型**：角落水印外侧是确定可采样的纯色背景，模型反而会引入纹理幻觉，且逐帧独立推理必然闪烁。

三步判定，全部为像素级确定性运算：

### 1. 底色采样

在 ROI 外圈取一条环带（外扩 `band` 像素，收敛到图像范围内，剔除 ROI 本身），对 RGB 三通道分别取**中位数**得到底色 `Cb`。中位数天然抗噪与抗少量杂散像素，并避开四角。自动采样值可在界面上被手动覆盖。

### 2. 按水印类型选择还原方式

| 水印类型 | 处理方式 |
| --- | --- |
| 不透明（`α≈1`） | 直接用 `Cb` 填充判定为水印的像素 |
| **半透明固定水印**（最常见） | **逆向 Alpha 解算**（见下） |
| 底色带轻微渐变/暗角 | 用 ROI 四边界的逆向距离加权插值代替单色填充 |

**逆向 Alpha 解算**是纯色背景下的最优解，它是数学精确复原而不是「猜测」：

混色方程为 `C_comp = α·C_wm + (1-α)·C_bg`，其中 `C_comp` 是当前像素、`C_wm` 是水印本色（通常为白）、`C_bg` 是步骤 1 采到的底色。令 `D = C_comp − C_bg`、`V = C_wm − C_bg`，则

```
α = clamp( (D · V) / (V · V), 0, 1 )      // 向量投影，最小二乘意义下抗噪
C_out = C_bg                              // 水印之下的真实内容就是纯底色
```

用 `α` 直接作为混合权重回写即可：`out = orig + (C_bg − orig) · α`。α≈0 的像素（底色本体）自然保持不变，α≈1 的被完全还原，抗锯齿边缘自动得到中间值——**不需要额外的阈值与羽化参数**。

退化保护：`V·V` 过小（水印色与底色几乎相同，如白色水印叠白色背景）时投影无意义，此时水印本身也不可见，直接退化为 `patch` 模式的蒙版填充。

### 3. 为什么逐帧无闪烁

`patch` / `alpha` 都是**参数固定的确定性函数**：底色、水印色、ROI 在样板帧上求一次，全部帧共用；噪点保留也必须用 **坐标哈希的伪随机数，禁止 `Math.random`**。因此同一水印在每一帧得到同一个 α 与同一份填充结果，时域完全稳定。这正是 AI inpaint 做不到的部分。

### 4. 边界退化规则

水印贴住图像角时，ROI 的某条边外侧没有像素。规则：**该边权重置 0 并在权重和上重新归一化**（角落最多丢两条边，朝图像内部的另两条必存在）；可用边 ≤1 时直接以 `Cb` 平填——水印贴角时该区域本就该是纯底色，平填即最优。

## 二、算法模块 `src/core/watermark.ts`（新增）

### 三种修复模式（同一套插值引擎，不写重复实现）

| 模式 | 语义 | 适用 |
| --- | --- | --- |
| `patch` | 按蒙版只替换判定为水印的像素 | 不透明水印、框选有余量 |
| `alpha` | 逆向 Alpha 还原，α 即混合权重 | 半透明固定水印（首选） |
| `region` | 无视蒙版，用四边界插值重建整个 ROI | 水印边界不确定、底色渐变强 |

> 说明：原本计划的独立「多轮 8 邻域扩散（Telea 简化版）」**不再单独实现**。四边界逆向距离加权插值本身就是 Telea 类扩散的核心思想，独立实现代码量更大、更慢、更易出刷痕，效果无明显提升。用 `region` 模式承载「整块重建」这一语义即可覆盖原本的扩散用途。

### 关键函数

```ts
/** 从 ROI 外圈环带中位采样底色；手动 baseColor 优先 */
function sampleRingColor(data: ImageData, rect: ImageCropRect, band: number, manual?: Rgb): Rgb

/** 曼哈顿色差 → 水印置信度蒙版（0-255），软过渡带避免硬边；仅 patch 模式使用 */
function buildMask(data: ImageData, rect: ImageCropRect, base: Rgb, threshold: number): Uint8ClampedArray

/** 四边界逆向距离加权插值：C=(Σ Ci/distᵢ)/Σ(1/distᵢ)；缺边权重置 0；可用边≤1 时平填 base */
function fillByEdges(data: ImageData, rect: ImageCropRect, base: Rgb): void

/** 逆向 Alpha 解算；V·V 过小时返回 null 交由调用方退化为 patch */
function recoverAlpha(data: ImageData, rect: ImageCropRect, base: Rgb, watermark: Rgb): boolean

/** 自动估算水印色：ROI 内沿 V 方向投影最大的像素的中位色 */
function estimateWatermarkColor(data: ImageData, rect: ImageCropRect, base: Rgb): Rgb

/**
 * 自动定位角落水印：长边降采样到 ~256px → 色差阈值二值化 → 栈式 flood fill 取连通域
 * → 选面积最大且不贴搜索窗内侧边的连通域，取包围盒 + padding 映射回图像坐标。
 * 不做形态学膨胀（降采样已足够抑噪），四角可指定或全自动。
 */
function detectWatermarkRect(data: ImageData, options): { rect: ImageCropRect; corner: Corner } | null

/** 单帧/单图入口：返回结果与蒙版（蒙版供界面诊断用） */
function watermarkImageData(image, ctx, source?: ImageData): { url: string; maskUrl: string; base: Rgb }

/** 批量：可取消、带进度；reuse 复用样板帧结果 */
function applyWatermarkToFrames(frames, ctx, options): Promise<number>
```

### 批量执行约定（保持既有不变式）

- 输入**固定为原始抽帧画面 `frame.url`**（与 `frame-matte.ts` / `frame-crop.ts`「始终从单一稳定源重算」一致），反复调参不叠加误差。
- 写入顺序必须是：`frame.watermarkUrl = 结果` → `frame.matteUrl = undefined` → `await recropFrame(frame)`。画面已变，旧的抠图结果失效，必须清掉（与 `FrameMatteModal.restoreFrame` 的语义一致）；不能自动重跑抠图，那会在 AI 模式下静默触发模型加载与逐帧推理。
- 参数（底色 / 水印色 / ROI）在样板帧求一次后全部帧共用，保证时域一致。

## 三、数据模型与展示优先级

`src/store/workspace.ts`：

```ts
export type WorkspacePage = 'atlas' | 'matte' | 'video' | 'watermark'

interface VideoFrame {
  ...
  /** 去水印结果（dataURL PNG），存在时作为抠图的输入 */
  watermarkUrl?: string
}

/** 去水印后的干净原图：作为抠图的输入（去水印 → 抠图 的稳定源） */
export function frameCleanUrl(frame: VideoFrame): string {
  return frame.watermarkUrl ?? frame.url
}

/** 裁切输入：抠图结果 > 去水印结果 > 原始抽帧画面 */
export function frameBaseUrl(frame: VideoFrame): string {
  return frame.matteUrl ?? frameCleanUrl(frame)
}

/** 展示/导出：裁切结果 > 抠图结果 > 去水印结果 > 原始抽帧画面（公式不变） */
export function frameImageUrl(frame: VideoFrame): string {
  return frame.cropUrl ?? frameBaseUrl(frame)
}
```

链路影响：`frameBaseUrl` 是裁切链路的唯一入口（`recropFrame` / `applyCropToFrames` / `FrameCropModal` / `FramePipelineModal`），改这一处即全链路生效；`frameImageUrl` 供帧卡片、动画预览、导出 ZIP 使用，因此去水印结果会自动参与展示与导出。

新增顶层 `workspace.watermark` 状态（单图模式需要独立状态，不塞进 `workspace.video`，否则 `resetVideo` 与 `persistMediaSettings` 的显式白名单会漏掉它）：

```ts
export interface WatermarkState {
  source: 'image' | 'frames'
  fileName: string
  sourceUrl: string
  resultUrl: string
  status: 'empty' | 'ready' | 'processing' | 'done' | 'error'
  error: string
  /** ROI（图像像素坐标），只在会话内保留，不写 localStorage */
  roi: ImageCropRect | null
  settings: WatermarkSettings
}

export interface WatermarkSettings {
  mode: 'patch' | 'alpha' | 'region'
  /** 水印本色 #rrggbb（alpha 模式解算用），默认白色；可吸管覆盖 */
  watermarkColor: string
  /** 水印置信度阈值，仅 patch 模式生效 */
  threshold: number
  /** 手动底色覆盖 #rrggbb，空 = 自动从 ROI 外圈采样 */
  baseColor: string
  /** patch 模式是否保留底色噪点（坐标哈希确定性噪声） */
  keepNoise: boolean
}
```

配套：新增 `resetWatermark()`；`persistMediaSettings()` 的白名单加入 `watermark.settings`（不含 `roi`）；读取本地设置后按现有 `MATTE_MODES` 的写法对 `mode` 做合法性收敛，丢弃已下线的取值。

## 六、验证方式

### 自动

```bash
pnpm run build          # vue-tsc -b && vite build，类型检查 + 构建必须通过
```

### 手动（`pnpm dev`）

1. **半透明角落水印（主场景）**：导入「纯色背景 + 右下角半透明白色水印」的图 → `alpha` 模式 → 自动定位 → 局部放大对比：水印消失且底色与原底色完全一致（用取色确认 RGB 相等，而不是「看起来差不多」）。
2. **不透明水印**：`patch` 模式，调阈值观察局部对比，确认未误伤背景与主体。
3. **渐变底色**：`region` 模式，确认无可见拼接痕。
4. **帧模式时域一致性**：抽帧后在同一 ROI 上「应用到全部帧」，逐帧翻看帧动画预览，确认无闪烁；帧卡片出现去水印标识；导出 ZIP 逐帧核对。
5. **边界**：水印贴住图像两条边（角落）时环带采样只取可用侧；ROI 拖出图像外被 clamp；`V·V` 过小的退化分支（白水印 + 白底）。
6. **链路联动**：先对某帧去水印，再打开「移除背景」弹窗，确认弹窗源图已是无水印画面、抠图结果无水印残留；随后执行「批量裁切」，确认裁切在去水印画面上进行。
7. **失效处理**：对已抠图的帧执行去水印，确认该帧抠图结果被清除并提示需重新抠图，画面回落到去水印结果而非旧抠图结果。

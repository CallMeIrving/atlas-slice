# 雪碧图（Sprite Sheet）改造实现方案

## Context

「智能图集打包」页已有 MaxRects 紧凑装箱、trim、旋转、预览落位与 TexturePacker JSON/plist 导出。对标成熟雪碧图工具，用户确认本轮补齐：**网格布局、动画预览、CSS/JSON 数组导出、extrude 边缘外扩、拖拽导入、多页打包、装箱启发式选择**；改名仅限界面文案（代码标识 `atlaspack`/`pack.ts`/`AtlasPackPage` 保留，无迁移风险）。

## 一、core/pack.ts（核心改造）

**类型扩展**：
```ts
export type PackLayout = 'compact' | 'grid'
export type PackHeuristic = 'bssf' | 'bl' | 'contact'
export interface PackOptions {
  // 现有 7 字段不动，新增：
  layout: PackLayout          // 默认 'compact'
  heuristic: PackHeuristic    // 仅 compact 生效
  gridColumns: number         // 0 = 自动 ceil(sqrt(n))
  gridCell: number            // 0 = 按最大内容尺寸+padding 自动
  extrude: 0 | 1 | 2          // 边缘外扩像素
}
export interface PackPage { width: number; height: number; placements: PackPlacement[]; fillRatio: number }
export interface PackMultiResult { pages: PackPage[]; errors: string[] } // errors：单素材超 maxSize 等
```

**实现要点**（全部加函数级中文注释）：
1. `packIntoBin` 增加启发式参数，抽出 `scorePlacement()`：bssf 沿用残留短/长边评分；bl 取 `y+h`（次选 `x+w`）最小；contact 取与已放置矩形及边界的接触周长最大。
2. 新增 `packPartialIntoBin()`：放不下的 box 跳过并记录，返回 placements + skipped。多页核心：以 maxSize 反复调用，skipped 溢出到下一页，直到清空或整页零放置（报「素材 X 超过最大尺寸」）。
3. 新增 `packItemsMultiPage(items, opts): PackMultiResult`；grid 布局走纯计算分支（不旋转、格内居中、按容量切片分页）。原 `packItems` 保留单页语义，与多页共享 `candidateSizes` 等内部函数，不生成重复代码。
4. **extrude 一致性**（先 trim 后 extrude）：盒子尺寸构造时即 `contentSize + padding*2 + extrude*2`，placement 几何直接含 extrude → renderAtlas 的 frame 与 meta 从同一 placement 推导，天然一致；`sourceSize` 不变。`drawPlacement` 改为先合成「内容+extrude」中间画布（四边+四角用边缘 1px 条拉伸复制），rotated 在合成后旋转贴入。
5. 导出 `drawFrame(ctx, atlasImage, placement)`：从图集抠帧（rotated 逆旋转还原），供动画预览复用。

## 二、core/atlas-meta.ts

- `buildAtlasJsonArray(meta, atlas, imageName)`：frames 为数组格式（每项附 filename），其余字段与哈希格式一致。
- `buildCssSprites(meta, imageName) → { css: string; skipped: string[] }`：标准 CSS sprites 规则；**rotated 帧跳过并返回名单**（CSS 无法无损表达旋转），由页面汇总提示。

## 三、store/workspace.ts

- `AtlasPackSettings` 新增 `layout/heuristic/gridColumns/gridCell/extrude/withCss/withJsonArray`（默认 compact/bssf/0/0/0/false/false）。settings 走 `Object.assign` 合并默认值，旧 localStorage 缺字段自动落默认，无需迁移。
- result 演进（result/previewUrl 不落盘，无兼容负担）：
```ts
export interface AtlasPackPageResult { width: number; height: number; fillRatio: number; placements: AtlasPackPlacement[] }
result: AtlasPackPageResult[] | null   // 多页数组
previewUrls: string[]                  // 每页 dataURL
activePage: number
```
- `resetAtlasPack()` 同步清空新字段。
- **TopBar.vue pageStatus 的 atlaspack 分支**同步改为读取 `result` 数组（如总落位数）。

## 四、AtlasPackPage.vue

- **改名**：侧栏标题、空状态、TopBar label 改「雪碧图」。
- **拖拽导入**：`tool-page` 根节点 `@dragover.prevent` + `@drop.prevent`，复用现有 `importFiles`（整批回滚逻辑保留）；dragenter 计数控制拖拽高亮遮罩。
- **参数区**：布局下拉（紧凑/网格）；网格时显示 列数/格尺寸（0=自动）并提示「网格模式不旋转」；紧凑时显示启发式下拉；extrude 下拉 0/1/2。`packOptions()` 透传新字段。
- **多页**：`pack()` 改调 `packItemsMultiPage` + 逐页 `renderAtlas`；预览头加分页 tab（各页尺寸与填充率），落位 overlay 按 `activePage` 渲染，单页时隐藏 tab。
- **导出**：按格式复选框循环 pages 产出 `atlas.png / atlas-2.png…` 与对应 `atlas.json / atlas-2.json / atlas-2.plist`、`atlas.css`、`atlas-array.json`（第一页不带序号）；CSS skipped 帧汇总提示。

## 五、动画预览：新组件 src/components/AtlasAnimationPreview.vue

- props：`previewUrls` / `pages` / `activePage`。atlas dataURL 经 `loadImage` 解码，用 pack.ts 的 `drawFrame()` 逐帧绘到 canvas（尺寸取当前页最大 sourceSize，居中），rotated 还原复用 core 不重复实现。
- 帧排序：默认文件名自然排序（`localeCompare(..., { numeric: true })`），下拉可切「落位序」；页切换重算帧列表。
- 控制：FPS（1–30，默认 12）、播放/暂停、循环开关；`requestAnimationFrame` + 时间累积驱动，卸载时取消。

# 图层预览选中和框选抠图交互方案

## Context

图层拆分功能当前流程为「导入图片 → 一键拆分（检测+分割+导出）→ 查看结果」，存在两个痛点：

1. **预览区不可交互**：拆分完成后，中央舞台只是展示合成画面，用户无法点击某个图层元素来选中右侧列表对应项。
2. **检测结果不可编辑**：AI 检测的框可能不准（范围偏大/偏小），也可能检出用户不需要的元素。用户希望能在拆分前预检、调整、删除框选区域，再按最终框选执行抠图。

## 方案概述

### 功能 1：预览区点击选中（小改动）

在 `LayerSplitStage.vue` 的 canvas 上加 click 事件，把视口坐标换算为图像像素坐标，找到 alphaBbox 包含该点的最顶层可见图层，通过新 emit 通知父组件选中。

**改动文件**：

* [LayerSplitStage.vue](file:///Users/oubuwen/D/testPro/atlas-slice/src/components/LayerSplitStage.vue) — 加 click handler + emit

* [LayerSplitPage.vue](file:///Users/oubuwen/D/testPro/atlas-slice/src/components/LayerSplitPage.vue) — 绑定 stage 的 select 事件到 selectedIds

### 功能 2：框选抠图交互（核心功能）

新增「检测 → 编辑框选 → 拆分」三步流程，替换当前的「一键拆分」：

```
导入图片 → [自动检测 / 手动框选] → 编辑框选（拖拽/缩放/删除/新增） → 按框选拆分 → 查看结果
```

#### 后端改动

**1. 新增** **`POST /api/layers/detect`** **端点**（仅检测，不分割不导出）

* 请求：图片文件 + `SplitParams`（只用 classes / detector / box\_threshold / text\_threshold / max\_side）

* 响应：同步返回检测结果（不创建 job），包含 boxes 列表

* 实现：复用 `run_pipeline` 的 decode + detect 阶段，在 runner.py 中提取 `detect_only` 函数

**2.** **`SplitParams`** **新增可选字段** **`override_boxes`**

* 类型：`list[UserBox] | None`，`UserBox = {x, y, w, h, label, category}`

* 当存在时跳过检测阶段，直接用用户框选执行 segment → refine → zorder → background → export

* 不存在时走现有流程（检测 → 分割 → 导出）

**改动文件**：

* [schemas.py](file:///Users/oubuwen/D/testPro/atlas-slice/server/app/schemas.py) — 加 `UserBox` 模型 + `override_boxes` 字段 + `DetectResult` 响应模型

* [layers.py](file:///Users/oubuwen/D/testPro/atlas-slice/server/app/routers/layers.py) — 加 `POST /detect` 路由

* [runner.py](file:///Users/oubuwen/D/testPro/atlas-slice/server/app/pipeline/runner.py) — 提取 `detect_only()` 函数；`run_pipeline` 中 override\_boxes 分支

#### 前端改动

**1. 新增** **`LayerBoxEditor.vue`** **组件**

多框编辑器，复用 FrameCropEditor 的坐标换算和拖拽模式：

* 渲染源图 + 叠加多个框（检测框用实线+类别色，用户新增框用虚线）

* 交互：点击选中框、拖动框体移动、8 控制点缩放、Delete 删除、空白处拖拽画新框

* 工具栏：自动检测按钮、添加框按钮、删除选中、全选/全删、确认拆分

* 输出：`Box[]` 数组（图像像素坐标 + 类别）

**2.** **`LayerSplitPage.vue`** **新增中间状态**

状态机扩展：`empty → ready → boxEditing → processing → done`

* `ready` 状态新增「框选编辑」按钮（替代直接拆分）

* `boxEditing` 状态显示 `LayerBoxEditor`，用户可自动检测或手动框选

* 用户确认后调用 `startSplit()` 并传入 `override_boxes`

* `done` 状态保持现有行为（显示 Stage + List）

**3.** **`layer-split.ts`** **新增** **`detectBoxes()`** **函数**

* 调用 `POST /api/layers/detect`

* 返回 `{ boxes: UserBox[], image: {width, height, scale} }`

## 实现步骤

### Step 1: 后端 — detect 端点 + override\_boxes

1. `schemas.py`：加 `UserBox(BaseModel)` + `DetectBoxOut(BaseModel)` + `DetectResultOut(BaseModel)`；`SplitParams` 加 `override_boxes: list[UserBox] | None = None`
2. `runner.py`：提取 `detect_only(image_bytes, params, models, settings, progress, check_cancel)` 函数；`run_pipeline` 中在 detect 阶段前判断 `override_boxes`，有则跳过检测
3. `layers.py`：加 `POST /detect` 路由（同步执行，返回 `DetectResultOut`）

### Step 2: 前端 — layer-split.ts API 层

1. 加 `detectBoxes(blob, fileName, settings)` 函数 → POST /api/layers/detect
2. `toServerParams()` 加 `override_boxes` 序列化
3. `startSplit()` 加 `overrideBoxes?: UserBox[]` 参数

### Step 3: 前端 — LayerBoxEditor.vue 组件

1. 布局：源图舞台 + 工具栏（自动检测 / 添加框 / 删除选中 / 确认拆分）
2. 框渲染：每个框 `<div>` 绝对定位 + 8 控制点 + 类别标签
3. 交互：pointerdown/move/up 实现拖拽移动、缩放、新建框
4. 坐标换算：复用 FrameCropEditor 的 imageRect 逻辑
5. 输出：emit `confirm` 事件带 `UserBox[]`

### Step 4: 前端 — LayerSplitPage.vue 集成

1. `boxEditing` 状态 + `userBoxes` ref
2. 「框选编辑」按钮 → 进入 boxEditing
3. boxEditing 时渲染 `LayerBoxEditor`
4. 确认后调用 `startSplit` 带 override\_boxes

### Step 5: 功能 1 — 预览区点击选中

1. `LayerSplitStage.vue` 加 click handler
2. 换算坐标 → 找最顶层匹配 → emit `select`
3. `LayerSplitPage.vue` 绑定事件

## 验证方式

1. `pnpm run build` 构建通过
2. `cd server && .venv/bin/python -m pytest -q` 测试通过
3. 手动测试流程：

   * 导入图片 → 点击「框选编辑」→ 点「自动检测」看到框 → 调整/删除部分框 → 画一个新框 → 点「确认拆分」→ 结果只包含用户保留的框

   * 拆分完成后点预览区某个元素 → 右侧列表对应项高亮选中
